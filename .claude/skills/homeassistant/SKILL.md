# Home Assistant Integration Development

This skill provides context for developing Home Assistant custom integrations.

## When to use

Trigger this skill when:
- Writing or reviewing HA integration code (config flows, entities, coordinators, services)
- Questions about HA patterns (e.g., "how should I implement config flow?", "what device class to use?")
- Debugging HA-specific issues (entity registration, coordinator errors, statistics import)
